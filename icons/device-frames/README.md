# Official Apple device artwork

`iphone-18-pro-black.png` is the unmodified portrait PNG from Apple's iPhone 18 Pro
product bezel package, downloaded from:
https://devimages-cdn.apple.com/design/resources/download/Bezel-iPhone-18.dmg

Source: https://developer.apple.com/design/resources/#product-bezels
Marketing guidance: https://developer.apple.com/app-store/marketing/guidelines/
The included Apple Design Resources License applies to this artwork.

Canvas: 1350 × 2760. Screen: 1206 × 2622, positioned at (72, 69).
The website places matching screenshots behind the complete PNG using CSS.
Do not crop, recolor, distort, or add shadows to the product artwork.
Pages without screenshots use the same official bezel around placeholder screens.
