# LinkedIn profile-link artwork

The current portfolio button uses unmodified official profile-link marks:

- `public/icons/linkedin-mark-blue.png`: `LI-In-Bug.png` (635 × 540).
- `public/icons/linkedin-mark-white.png`: `InBug-White.png` (840 × 779).

Downloaded October 12, 2026 from the archive linked by LinkedIn's Downloads page:
https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip

Usage guidance: https://brand.linkedin.com/in-logo
Download page: https://brand.linkedin.com/downloads

LinkedIn's guidance explicitly permits its [in] mark as a hyperlink to a member's
profile. The portfolio uses the blue mark on light surfaces and white mark on dark
surfaces, scaled proportionally to 21px high. A separate visible LinkedIn label
names the destination without recreating a wordmark. The fixed picture container
accommodates the official assets' different canvas proportions without moving the
label. Both system appearance and manual appearance selections switch the assets.
